Hello test: Debian GNU/Linux packages

This repository holds the Debian GNU/Linux packages of Hello test, signed with its key.

Installation

On Debian GNU/Linux 12 (Bookworm)

sudo curl -fsSL -o /usr/share/keyrings/hello-archive-keyring.gpg https://repo.example.org/debian/hello-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/hello.sources <<'EOF'
Types: deb
URIs: https://repo.example.org/debian
Suites: bookworm
Components: main
Signed-By: /usr/share/keyrings/hello-archive-keyring.gpg
EOF
sudo apt update

On Debian GNU/Linux unstable (Sid)

sudo curl -fsSL -o /usr/share/keyrings/hello-archive-keyring.gpg https://repo.example.org/debian/hello-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/hello.sources <<'EOF'
Types: deb
URIs: https://repo.example.org/debian
Suites: sid
Components: main
Signed-By: /usr/share/keyrings/hello-archive-keyring.gpg
EOF
sudo apt update
