Hello test: Fedora Linux packages

This repository holds the Fedora Linux packages of Hello test, signed with its key.

Installation

On Fedora Linux 44

sudo curl -fsSL -o /etc/yum.repos.d/hello.repo https://repo.example.org/fedora/44/hello.repo

dnf asks to trust the key at the first installation from https://repo.example.org/fedora/44.
